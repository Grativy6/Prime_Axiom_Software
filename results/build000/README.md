# Build 000 checked evidence

The complete verification run, including test execution and the checked sanitized test summary, is generated with:

```powershell
& .\scripts\verify.ps1
```

The experiment subcommand recorded in `manifest.json` generates the JSON, CSV, benchmark, and SVG artifacts; the verification script also performs locked restore, formatting, Release build, and tests.

Files:

- `manifest.json`: environment, deterministic seed, assembly SHA-256, command, and claim ceiling.
- `correctness.json`: independent bounded correctness domain and failures.
- `fair_domain_costs.csv`: matched universal-range dense-prime versus binary logical cost sweep.
- `resident_multiplication_workloads.csv`: factor-resident seeded workload comparison.
- `representation_cases.csv`: payload, factorization, and basis-escape cases.
- `addition_disruption.csv`: deterministic support-change and trial-factorization observations.
- `operation_preimages.csv`: bounded addition/multiplication preimage control.
- `microbenchmarks.csv`: host-specific managed timings; not hardware evidence.
- `figures/fair_domain_gate_counts.svg`: visualization generated directly from the fair-domain rows.
- `test-summary.json`: sanitized 35-test Release counters, timestamps, command, configuration, and test-assembly hash generated by `scripts/verify.ps1`. The identity-bearing raw TRX stays under ignored `.artifacts/`.

Functional and gate-count rows are deterministic for this code and runtime semantics. Wall-clock rows are expected to vary. Regeneration overwrites only these named evidence files.
